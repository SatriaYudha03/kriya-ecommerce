# Report B6: Admin pelanggan & pengaturan

## 1. Konteks
Task B6:
- Membuat endpoint backend untuk daftar pelanggan, detail pelanggan, dan pengaturan toko.
- Membuat halaman frontend admin untuk melihat pelanggan dan mengatur konfigurasi toko.

## 2. Perubahan Utama
- `services/api/internal/customer/admin_customer_repo.go` & handler: Query data auth.users dan profile, orders untuk statistik.
- `services/api/internal/customer/settings_repo.go` & handler: Query/update `store_settings`.
- `apps/web/app/(admin)/admin/customers/page.tsx`: Tabel daftar pelanggan (pagination, sort, search).
- `apps/web/app/(admin)/admin/customers/[id]/page.tsx`: Detail pelanggan dengan order stat, history, alamat.
- `apps/web/app/(admin)/admin/settings/page.tsx`: Form update `store_settings`.
- `apps/web/lib/customer/api.ts` & `queries.ts`: Mengaitkan endpoint B6.
