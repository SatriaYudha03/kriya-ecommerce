## 1. Lingkup Pengerjaan
1. Menambahkan endpoint GET `/categories` untuk memberikan response berupa tree (kategori + navigasi) jika terdapat parent. Modifikasi pada model dan repository Go untuk filter `parent_id` dan properti `is_active`.
2. Membuat endpoint CRUD `/admin/categories` beserta handler dan repository admin untuk manipulasi kategori secara lengkap (parent_id, image_path, description_i18n).
3. Modifikasi fungsi filter produk agar kategori mengambil produk dari kategori bersangkutan beserta subkategorinya menggunakan `WITH RECURSIVE cat_tree` di kueri `GetProducts`.
4. Membuat halaman admin `/admin/catalog/categories` pada Frontend yang berisi tabel hierarki kategori beserta manajemen `category-form`.
5. Modifikasi halaman kategori publik `/categories/[slug]` agar menampilkan breadcrumbs berlapis, subkategori (jika ada), serta deskripsi dan gambar kategori secara dinamis.
