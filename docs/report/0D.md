   ```
   $ cd scripts/ec-v2/mintjwt && go build .
   go: go.mod file not found in current directory or any parent directory; see 'go help modules'
   ```
   Tidak ada `go.mod` di `scripts/ec-v2/mintjwt/` maupun di `scripts/ec-v2/`. Mencoba
   build dari `services/api` (modul yang punya dependency serupa) juga gagal:
   `directory ..\..\scripts\ec-v2\mintjwt outside main module or its selected
   dependencies`. Tool ini **belum pernah benar-benar dijalankan** — klaim laporan asli
   "diimplementasikan clean tanpa memicu teguran type data" tidak akurat: kegagalannya
   terjadi di tahap resolusi module, sebelum compiler sampai memeriksa tipe apa pun.

   Detail tambahan: `main.go` mengimpor `github.com/golang-jwt/jwt/v4`, sedangkan
   `services/api/go.mod` memakai `github.com/golang-jwt/jwt/v5` — inkonsistensi versi
   yang akan perlu diselaraskan saat `go.mod` untuk tool ini akhirnya dibuat.

   **Dampak:** `mintjwt` adalah tool yang dirujuk EKSEKUSI-PARALEL-V2.md §2.1 sebagai
   cara SEMUA agent F1 (A/B/C/D) mint token JWT uji. Selama belum diperbaiki, task
   apa pun yang butuh token JWT uji per-akun tidak punya cara resmi untuk itu.
