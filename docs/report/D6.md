## Lingkup yang dikerjakan
- Backend: Endpoint `GET /notifications` (dengan paginasi dan filter unread), `GET /notifications/unread-count`, dan `POST /notifications/read` telah diimplementasikan dalam `notifications_handler.go` beserta repository-nya `notifications_repo.go`.
- Backend: Logic `Events.Record` di `events.go` telah diperbarui dengan template dwibahasa (ID/EN) untuk transisi status order (paid, processing, shipped, completed, cancelled, refunded) agar membuat notifikasi dengan format yang tepat. Resi (tracking number) juga telah disertakan ke body notifikasi jika tipe transisi adalah shipped.
- Backend: Repositori order note `admin_repo.go` (AddOrderNote) telah diperbarui agar membuat notifikasi bertipe `order_note` ketika status `isCustomerVisible` bernilai true.
- Backend: Repositori return `returns_repo.go` (UpdateReturnStatus) juga diperbarui untuk membuat notifikasi `return_update`.
- Frontend: Komponen stub `NotificationBell` telah diimplementasikan dan menampilkan badge jumlah notifikasi (polling unread count tiap 60 detik menggunakan `refetchInterval` TanStack Query).
- Frontend: Halaman `/account/notifications` ditambahkan untuk melisting notifikasi user.
- Frontend: Halaman invoice `/orders/[id]/invoice` (siap cetak dengan class CSS `print:`) telah dibuat menampilkan data-data yang diminta (Store Info ditarik melalui dummy hook `getStoreInfo()`).
- Frontend: I18n translations untuk invoice dan notifikasi ditambahkan untuk `en` dan `id`.
